<a href="https://github.com/MahardikaPratama/Webdev-Praktikum">
<img src="https://img.shields.io/badge/View%20Project-2196F3?style=for-the-badge&logo=github&logoColor=white">
</a>

</div>

<p align="left">
<b>DramaKu</b> is a web platform designed for drama and TV series enthusiasts, similar to IMDb.
</p>

<p align="left">
The application provides comprehensive information about dramas, actors, ratings, reviews, genres, awards, and users.
</p>

<p align="left">
<b>Main Features:</b>
</p>

<ul>
<li>Main page with search and filtering functionality</li>
<li>Drama details, ratings, cast, reviews, and synopsis</li>
<li>CMS for dramas, actors, countries, genres, comments, awards, and users</li>
<li>User registration, login, Google authentication, wishlist, and profile management</li>
<li>Validation and user restriction features</li>
<li>CRUD operations for multiple entities</li>
<li>Dashboard with statistics for dramas, actors, genres, comments, and users</li>
</ul>

<p align="left">
Data is sourced from <b>The Movie Database (TMDb)</b>.
</p>

<div align="center">

<code>React</code>
<code>Node.js</code>
<code>Express.js</code>
<code>PostgreSQL</code>
<code>TailwindCSS</code>
